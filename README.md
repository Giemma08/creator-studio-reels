Worker 5 des AI is Female Creator Studio: Reels schneiden.
Alle Dateien liegen bewusst auf einer Ebene, damit sie sich einfach hochladen lassen.

- index.js, ui.js, sounds.js: Worker (Oberfläche, Hochladen, Aufträge, Credits)
- server.cjs, render.cjs, Dockerfile: Schnitt-Werkstatt im Container
- *.wav: selbst erzeugte Töne, frei nutzbar
- Poppins-Bold.ttf: SIL Open Font License (OFL.txt)
- Die Datei .github/workflows/deploy.yml wird in GitHub von Hand angelegt (siehe Anleitung)
